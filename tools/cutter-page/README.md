# Cutter sales page

The cutter/ folder is a standalone sales page for Tomas's Cutter program (cutting plans from Blum's Cabinet Configurator).
English is at /cutter/ and Polish is at /cutter/pl/. It was added on 23 Nov 2026 at the owner's request.

It is not built by build.sh or by the "Deploy site" workflow.

The two pages, cutter/index.html and cutter/pl/index.html, are generated by:

    python3 tools/cutter-page/build.py

Change the text in build.py, run it, and commit the two index.html files. Do not edit the HTML by hand.
cutter/fonts/ (Heebo) and cutter/img/ (screenshots and video poster) are plain files, not generated.
The owner decides the wording of the page.
